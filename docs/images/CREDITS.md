## Comparison images (`compare-dwaa.jpg`, `compare-zip.jpg`)

Derived from **NAS Sole Mates - HDR Production Example**, frame 1037 of
`exr_sequences/unh0400_0010_lighting`, from the ASWF Digital Production Example
Library (<https://dpel.aswf.io/solemates>).

NAS Sole Mates - HDR Production Example Copyright 2025 Netflix, Inc. All rights reserved.

How these images differ from the original asset: each panel is a Finder
thumbnail generated by macOS Quick Look from the frame, downscaled to 760 px
wide and JPEG-compressed. For `compare-dwaa.jpg` the frame was first re-encoded
from ZIP to DWAA compression (level 45) with the OpenEXR library; pixel values
are otherwise unchanged. The left-hand panels show macOS's built-in rendering,
the right-hand panels EXR Quick Look's. The source frames are not
redistributed in this repository.
